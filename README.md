项目用于帮助加速线上学习。
使用方法：浏览器F12打开控制台，将代码粘贴进去回车即可激活（一次只能粘贴一个文件，两个一块会出问题）。
如果关闭网站或是刷新网站则效果消失，将代码保存为油猴脚本可以长期使用。

一键推进进度.js:
在网课视频或ppt或考试页面调出控制台使用
加载后网页弹出窗口包含多个按键，点击一键刷课即可自动从当前节开始完成之后所有的ppt,视频，小测验。
注意，测验在不及格后会告知所有答案，然后程序会自动满分作答。代价是第一遍全选A，整体正确率略高于50%。
刷完劳动课约5分钟

增加统计时长.js:
在视频页面控制台使用，回车后会出现弹窗展示捕获的发到服务器的学习时长记录信息。
脚本参数设置为发送频率200倍，时长参数100倍
效果为每3秒发送一条请求，增加100分钟的学习时长记录。
经过实测学习统计里的时长数据不影响通过，(一天学习1613分钟和一整个课程5分钟学完全都算通过)
