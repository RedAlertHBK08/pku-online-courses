## 项目简介
用自己的劳动帮助大家，这何尝不是一种劳动课程

本项目用于辅助加速部分线上学习平台的课程进度，包含两个独立脚本：

- `一键推进进度.js`
- `增加统计时长.js`

脚本通过浏览器控制台运行。由于两个脚本同时粘贴可能产生冲突，请一次只粘贴并运行一个文件。

本项目初始代码主要由 DeepSeek 免费版通过 vibe coding 方式辅助完成。如果担心安全性可以借助AI检查

## 使用方法

1. 打开目标线上学习页面(例如视频课播放界面)
2. 按下 `F12` 打开浏览器开发者工具，切换到 `Console` 控制台。
3. 复制其中一个脚本的完整代码，粘贴到控制台后按回车执行。
4. 页面出现弹窗后，根据弹窗按钮进行操作。
5. 关闭页面或刷新页面后，脚本效果会消失。
6. 如需长期使用，可将代码保存为 Tampermonkey 等用户脚本管理器支持的油猴脚本。
7. 如对代码安全性有疑虑，建议先让 AI 或专业人员审查代码。
8. 如不熟悉浏览器控制台操作，也可以向 AI 咨询具体步骤。

> 注意：一次只能粘贴一个文件。同时粘贴两个脚本可能会出现问题。

## 脚本说明

### 一键推进进度.js

适用页面：网课视频、PPT、测验或考试页面。

功能说明：

- 加载后页面会弹出操作窗口，包含多个按钮。
- 点击“一键刷课”后，脚本会从当前节开始，自动完成后续的 PPT、视频和小测验。
- 其他按钮基本没用，有兴趣的大佬可以更新一下删掉冗余
- 测验机制：利用网页测验未通过时会告知答案，第一遍默认全选 A，，随后程序会自动满分作答。整体正确率略高于 50%。（这一数值不影响通过，介意的话可以让deepseek改代码)
- 参考耗时：刷完劳动课约需 5 分钟。


### 增加统计时长.js

适用页面：视频学习页面。

功能说明：

- 在控制台运行后，会弹出窗口展示捕获到的、发往服务器的学习时长记录信息。
- 脚本参数设置为发送频率 200 倍，时长参数 100 倍。
- 效果为约每 3 秒发送一条请求，增加 100 分钟的学习时长记录，时间会略有误差。
- 每次会捕获2条请求，一个是正常请求一个是修改的请求，例如捕获20条请求时，学习时长统计会增加约1000分钟。
- 实测学习统计中的时长数据可能不影响课程通过判定，一些离谱的数据，例如一天学习 1613 分钟或整门课程 5 分钟完成，均通过

实现方式：

- 该脚本在数据加密之前截取明文并进行修改。
- 因此，对于学习时长数据，本脚本主要用于观察、调试和实验。是否使用请自行判断，并确保符合平台规则。

## 原理简述

- `一键推进进度.js`：采取自动化操作前端的方式完成课程流程。
- 平台判定是否完成学习：依据客户端发送的加密信息。
- `增加统计时长.js`：在加密之前截取明文并修改学习时长数据。
